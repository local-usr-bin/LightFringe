# 有限多缝干涉 A3

软件源码版本0.2.0，构建LF-P0-A3-MULTISLIT-R1。仅新增等宽、等间距、同相等幅照明的有限多缝；没有近场、色散、多波长、绝对光强或N>8。

## 操作

继续使用 `F:\DevProjects\LightFringe\run.cmd`。第三模式“多缝干涉”显示整数缝数控件，N=3—8。波长、缝宽、中心距和屏距的滑块及数值框用法沿用原界面，数值输入回车确认。

第一次进入多缝采用预检通过的 N8、550 nm、a20 μm、d60 μm、L2.00 m。之后多缝与原单/双缝的参数组分别记忆于当前窗口；单/双缝之间仍按原共享参数逻辑切换。多缝恢复默认不重置原模式参数；原模式恢复默认仍回到原双缝默认值。关闭程序不新增磁盘设置持久化。

界面沿用屏距符号z；科学推导中的L与z是同一个距离。多缝显示 I/Imax，理想模型 Imax=I(0)，与A1/A2原有按轴上峰值归一化口径相同；没有按当前采样数组重新缩放峰高。

## 模型和保护

令 t=dx/(λL)，r=t−rint(t)，多缝光强为：

`np.sinc(a*x/(λ*L))**2 * (np.sinc(N*r)/np.sinc(r))**2`

NumPy sinc带π，且|r|≤1/2，因此分母远离零，整数相位及中央的极限自然为1。没有用近峰阈值补平台，也没有裁剪、平滑或硬截断计算结果。有效输出检查有限、非负且≤1。

完整孔径W=(N−1)d+a；F=(W/2)²/(λL)≤0.05；|x|/L≤0.05。波长380—750nm、缝宽10—80μm、中心距40—250μm、屏距0.50—3.00m的原外框未扩大。GUI保持至少5μm缝隙，科学API拒绝接触或重叠。N增大时可能使同一组参数失效，此时清除旧数据、光纹和曲线，暂停导出并说明原因。

局部窄峰依靠完整孔径带宽保护：最短周期λL/W，而不是只检查主要峰间距λL/d。实际设备像素每最短周期必须≥12，曲线继续每物理像素4顶点，光纹继续16子点线性强度平均后平方根灰度。采样不足时隐藏结果；不会自动更改N或其它参数来掩盖问题。

新代码位于multislit.py。N1/N2的求解、采样分发到原model.py和sampling.py，原三模块model/sampling/rendering字节不变。新参数数据类包含N，因此计算键、陈旧检查和不可变PDF快照也包含N。

## PDF

沿用已验收的系统保存对话框、取消/覆盖确认、成功/失败提示及QSaveFile原子提交。新增的是多缝文件名和报告内容，未改动对话框确认选项或写入安全流程。报告使用捕获时的同一有效快照；保存对话框期间改变N或模式不会拼接新旧结果。

多缝报告记录N、同相等幅假设、四参数、W/F、相对光强曲线、光纹、包络、缺级及中央主峰首零点间宽。首零点在视场外时明确说明。保留单/双缝的原结构与科学单位；软件信息注明当前A3版本，旧模式同时标明所沿用的LF-P0-A2-R1核心基线，避免混淆当前构建与已审模型来源。

曲线和文字为矢量；缩小查看会降低物理像素密度，报告给出按本次最短周期计算并向上取整的建议有效dpi。该值由显示器DPI和缩放共同决定，不表示PDF曲线本身只有固定像素。灰度图是辅助图，Qt可能JPEG编码；不把RGB或灰度值当实测光强。
