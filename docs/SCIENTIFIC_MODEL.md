# 科学模型与适用条件

LF-P0-A1-R1，2026-11-10。

## 物理假设

单色、完全相干、均匀等幅的平面波垂直入射；孔径为同宽长直缝，考察垂直缝方向的一维截面。只计算标量、傍轴、夫琅禾费远场归一化相对光强。不计算有限缝高的二维衍射、偏振、材料边界、部分相干、光源光谱、探测器噪声或屏面绝对照度。

无限长缝在纵向理想化；这里的远场准则针对横向截面，不能用它声称任意实际有限缝高的整张二维屏均处在远场。

设缝宽 a、双缝中心间距 d、波长 λ、屏距 z、屏幕横坐标 x，内部全用 SI 单位。

## 解析表达式

令 β = π a x/(λ z)，α = π d x/(λ z)，sinc(t)=sin(t)/t，sinc(0)=1。

- 单缝：I(x)/I(0) = sinc²(β)。
- 双缝：I(x)/I(0) = sinc²(β) cos²(α)。

NumPy 的 `np.sinc(u)` 定义为 sin(πu)/(πu)，因此实现传入 `a*x/(λ*z)`，不能额外再乘 π。中央位置使用 `np.sinc` 的稳定极限。

双缝式由两个相隔 d 的有限矩形孔径的复振幅相加得到，完整保留缝宽包络。各配置按自身中央强度归一化；没有把双缝改成两个理想点源。忽略绝对尺度后，双缝曲线的干涉因子周期为 λz/d，包络首零点为 ±λz/a。乘积的侧峰位置可能偏离纯 cos² 因子的极大位置，界面因此称“干涉因子周期”。

公式可与 [MIT 2.710 双缝 Fourier 孔径推导](https://web.mit.edu/2.710/Fall06/practice02.pdf) 核对。关于舍弃孔径二次相位及标量傍轴近似，参见 [田纳西大学衍射课程](https://labs.phys.utk.edu/mbreinig/phys421/modules/m6/Fresnel.html)。本文阈值及以下误差讨论是本项目明确选择的工程约束，不是文献给出的统一精度保证。

## 有效域与阻断

完整横向孔径宽 D：单缝 D=a；双缝 D=d+a。令 R=D/2，定义 F=R²/(λz)。要求 F≤0.05。注意 Fresnel 数在不同资料中可能采用全宽或半宽；本项目始终明确使用半宽，双缝计算包含两缝之间的跨度。

从傍轴积分到夫琅禾费模型舍弃的孔径二次相位最大为 πF，本阈值限制为约 0.157 rad。默认双缝 F=0.0147273，对应上限约 0.0463 rad。这个条件是远场近似的准入条件，不能等同于所有位置相对强度误差低于某个百分比；特别是零点附近相对误差不能这样界定，真实有限距离实验中的“缺级”可能存在小残余。

本轮没有实现近场求解器。F 超标时科学 API 抛出 ModelError；GUI 删除当前数据和图像，显示暂停原因，不继续给出看似可靠的预测。

横向采用傍轴坐标 x/z，而非在公式中混入精确 sin(arctan(x/z))。要求 |x|/z≤0.05，显示半宽为 min(40 mm, 0.05 z)。在边界处，用 x/z 代替精确正弦的相对几何偏差为 sqrt(1+0.05²)-1≈0.125%；这不是完整强度误差界。所有坐标刻度随实际视场更新。

## 控件范围

| 参数 | 范围 | 步长 |
|---|---|---|
| λ | 380–750 nm | 1 nm |
| a | 10–80 μm | 1 μm |
| d | 40–250 μm（双缝） | 1 μm |
| z | 0.50–3.00 m | 0.01 m |

GUI 进一步保证 d≥a+5 μm；科学 API 要求严格 d>a。控件外框允许探索不同组合，但组合必须同时通过 F 条件才显示物理预测。例如 λ=380 nm、a=80 μm、d=250 μm、z=0.5 m 时 F≈0.143289，明确阻断。无效数值、NaN、Inf、非正值、越界坐标及孔径接触/重叠均拒绝。

最小缝宽至少为最大波长的 13.3 倍，这是本轮避免亚波长孔径问题的范围选择，不表示已解决真实材料和矢量边界问题。

## 默认数值与缺级

λ=550 nm、a=30 μm、d=150 μm、z=1.0 m。

| 量 | 独立预期 |
|---|---|
| 单缝包络首零点 | ±18.3333333333 mm |
| 干涉因子周期 | 3.66666666667 mm |
| 双缝首个纯干涉暗纹 | ±1.83333333333 mm |
| 单缝 x=9.16666666667 mm | 4/π²=0.4052847345693511 |
| 双缝 x=3.66666666667 mm | [sin(π/5)/(π/5)]²=0.8751402000833809 |
| 双缝缺级 | d/a=5，每第 5 级纯干涉极大与包络零点重合 |

默认第 ±5 级在 ±18.3333 mm 缺级，第 ±10 级也缺级；邻级不消失。这里的零为理想远场模型的预测，浮点计算可保留约 10⁻³³ 的残余，显示没有硬截断物理结果。

## 采样和辅助显示

强度的空间频谱等于孔径频谱的自相关，最大空间频率为 D/(λz)，故最短空间周期保守取 λz/D。按窗口实际 devicePixelRatio 计算物理像素数，要求每最短周期至少 12 像素。若不足，条纹及曲线同时隐藏，并清除旧图；不会依赖颜色或插值“修好”欠采样结果。

通过门槛后，每个屏幕像素用 16 个等距中点样本平均线性强度，再施加平方根亮度映射和 8-bit 灰度量化。默认 1000 像素宽时与 20000 子点/像素的独立参考积分差值受测试约束为 <3×10⁻⁶（所测试像素）；这是数值像素平均近似，不是实际探测器模型或对所有配置的误差保证。

曲线每个物理像素取四段，含精确原点和端点；原始采样保持线性。为了降低 Qt 软件光栅器开销，只在渲染顶点中舍去近共线点，以全体原始样点相对于保留顶点线性插值的最大纵向误差 ≤0.15 个物理像素为约束。数值数据与屏幕像素平均不受此操作影响。独立测试用 `np.interp` 验证该上界。抗锯齿、8-bit 量化与线宽仍是显示限制，不是数值精度。

观察屏不叠加坐标网格，以免网格形成假亮纹。灰度不是光谱颜色，不把显示 RGB 当作测量。观察屏高度只是将同一一维截面纵向重复，不表示二维有限孔径模拟。装置示意图明确标注“不按比例”。

## 验证策略

测试包含手算常数、零点和缺级位置，以及对真实单缝/双缝开口区间的独立复指数孔径积分（每缝 16000 点中点积分）。该积分不调用生产代码的 sinc/cos 表达式，误差容限 8×10⁻⁹。它验证的是当前远场解析实现，不是对实验、完整 Maxwell 模型或近场近似误差的验证。

其余验证包括参数变化的方向和数值、中心稳定、对称、边界、非法几何、远场准入、像素积分、欠采样阻断/恢复以及真实 Qt 控件事件。详见 `tests/test_model.py`、`tests/test_gui.py` 和 `artifacts/tests.txt`。
